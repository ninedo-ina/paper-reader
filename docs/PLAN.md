# PaperReader 迭代计划

## 当前迭代：v0.1.12

分支：`feature/v0.1.12`

### 目标

优化浏览器标签页 favicon：缩小单字母 R，并让它在浅色和深色方形图标中保持水平、垂直严格居中。

### 已完成

- 两个主题 favicon 均将 R 缩小到更合适的视觉比例。
- R 的几何边界以 64×64 图标中心为基准重新定位，确保上下左右居中。
- 浅色背景使用深色 R，深色背景使用浅色 R，保持主题切换适配。
- 更新 favicon 缓存参数及 v0.1.12 版本信息。
- 保持首页左上角品牌 Logo 不变，本次只调整浏览器标签页图标。

### 验收标准

- 浏览器请求带有 `v=0.1.12-r1` 的 favicon 缓存参数。
- 浅色和深色 favicon 均可正常返回，且 SVG 结构有效。
- R 在方形图标内视觉尺寸适中、水平居中、垂直居中。
- 首页左上角 Logo 与页面其他品牌元素未被本次修改影响。
- 构建、测试、重启和公网检查均通过。
