# PaperReader 迭代计划

## 当前迭代：v0.1.12-fix

分支：`feature/v0.1.12-fix`

### 目标

修复侧栏折叠按钮的点击层级问题，确保按钮跨越侧栏边界时左右两半都可以点击。

### 已完成

- 侧栏自身提升到明确的层级，避免跨边界的按钮被相邻 flex 内容覆盖。
- 折叠按钮提升到侧栏内部的高层级，保持原有边界居中位置和尺寸。
- 展开与收起状态均复用同一个可点击按钮，不改变现有状态逻辑。
- 统一更新 `0.1.12-fix` 版本信息和 favicon 缓存参数。
- 初始化 `main`/`dev` 分支工作流，并将 `main` 设置为仓库默认分支；保留所有历史版本分支。

### 验收标准

- 折叠按钮左半区和右半区点击都能触发展开/收起。
- 展开和收起两种状态下按钮仍位于侧栏边界中间，不挤压品牌区域。
- 浏览器请求带有 `v=0.1.12-fix-r1` 的 favicon 缓存参数。
- 首页左上角 Logo 与页面其他品牌元素未被本次修复影响。
- 构建、测试、重启和公网检查均通过。
